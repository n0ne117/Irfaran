    Settings

    No API token is set. This browser can look at the map and nothing else — drawing, pins, imports and every setting that reaches the server are switched off until one is entered under Security.

    Interface theme

    Panels and controls. Independent of the map.

    Map theme

    Basemap, fog colour and trail colours. Both themes were rendered at import, so switching is instant.

    Fog

    How much of the map shows through ground you have not visited. At 100% the world behind is completely hidden. Applied in the browser, so it changes as you drag and nothing is re-rendered.

    Set per map theme — this is the dark one. Unlike thickness, the colour is baked into the tiles, so applying it re-renders them. On a full archive that takes several minutes, and the settings stay locked until it finishes.

    Tracks

    Detailed draws one legible line per track, which is right until a hundred of them share a street and the whole area turns white. Single draws one line per route instead of per journey, so a commute walked four hundred times is drawn once. Faint draws hairlines that add up, so how often you went somewhere becomes the brightness. Auto picks between detailed and faint to suit what is on screen. The trail colouring underneath is unaffected in every mode — that is what already says how often you went.

    Only so many tracks are sent for one viewport, and by default a line above the time bar says so when the rest have been left out. Turning this off does not draw any more of them — it stops mentioning it.

    Trail colouring

    How often a pixel was crossed, on a log scale. Strength is applied in the browser and changes as you drag; the colours are baked into the tiles, so changing those re-renders them.

    Borders

    Drawn above the fog, so they stay readable over ground you have never been. The basemap has its own borders underneath, which the fog hides.

    Projection

    The globe is a globe while you are looking at the world and flattens itself into Mercator on the way in, so a footpath is still drawn on something flat. Per browser, like the borders and the scale bar.

    Equal Earth is greyed out rather than missing. MapLibre has three projections compiled into its shaders and that is not one of them, so there is nothing to switch on yet — but it is the one worth waiting for: it is equal-area, and Mercator is the projection that lies about exactly the thing the statistics page measures.

    Scale bar

    Bottom right, above the attribution. Metric, and it shortens as you go north — the same zoom covers half as much ground in Tromsø as in Vienna. Hidden on a narrow screen whatever this says, because the time bar and the attribution already share that edge.

    Brush

    A stroke is filed under whatever the time bar is showing. Select a year and draw, and it belongs to that year. On All time or Before records it goes to prehistory, where undated memories live.

    Drawing on the map

    Use the pencil at the top right of the map to open the drawing toolbar. Drawing needs zoom 14 or closer: below that one screen pixel is wider than the brush, so the geometry would be meaningless.

    Open in Maps

    A clicked pin offers a link to the same spot in one of these, for the things Irfaran does not know — routing, opening hours, what a place is called this year. Only the coordinates are sent: not the pin's name, not its label, not who was there. Per browser, because the right answer on a phone is not the right answer on a desktop.

    Export

    Everything worth keeping, as one file: the event log, your pins, labels and folders, and how the map is set to look. Not the tiles or the blobs — those are rebuilt from the events, byte for byte — and not the basemap, which the other instance can fetch itself. Your API token stays behind too; it belongs to this server.

    Import

    Merges a backup into this instance. Nothing is deleted and nothing is overwritten — importing the same file twice changes nothing the second time. Afterwards the map is redrawn, which on a large archive takes a few minutes.

    Import workout files

    GPX and TCX. Files are imported one at a time, and re-importing something you already have changes nothing, so it is safe to select everything at once.

    Workout trackers

    Services that already hold your activities. Nothing is pushed here — Irfaran asks, on a timer or when you press the button. Activities are filed as workouts, the same as a file you drop in under Import, so anything already imported is recognised rather than drawn a second time.

    From intervals.icu, Settings, Developer. Stored on this server and never sent back to any browser, so this field is blank every time you open it — leaving it blank keeps the key you already saved.

    Leave the athlete as 0 for whoever the key belongs to. Zero hours means never on its own — only the button below.

    Live tracking

    All off by default. While a source is off its endpoint refuses politely, so a misconfigured tracker tells you what is wrong rather than losing your location silently. See the README for tracker setup.

    Hold automatic data back

    A file you drop in and a line you draw are things you were already looking at. The automatic sources are not: a tracker hands over whatever was uploaded to it, and a phone posts wherever it has been all day. With a source ticked here, what it sends waits to be looked at instead of going straight onto the map — and what waits is .

    Nothing held has entered the archive. Discarding one leaves no trace to find and delete afterwards, which is the whole point of the delay.

    Live sources are held a day at a time, because that is the unit they are stored in. Opening one for review seals it: points that arrive afterwards start the next batch rather than joining the one you are reading.

    Ground covered

    —

    Fog cleared, water included — a ferry crossing is as much a place you have been as a footpath. Measured on the ground rather than on the screen: a pixel near the poles covers a fraction of what one at the equator does, and every one is weighted accordingly.

    Countries

    —

    —

    Borders come from Natural Earth's most detailed free set, public domain, shipped with Irfaran — the basemap carries border lines rather than closed shapes, so there is nothing in it to test a point against. Ground is attributed per pixel, about six metres, not per tile: a tile is over a kilometre across here, and handing a whole one to whichever country its centre falls in would invent the wrong country along every border. Somewhere you dropped a pin always counts, however little ground it covers.

    Welcome to Irfaran

    Irfaran draws your fog and trails over a map of the world. That map is a Protomaps PMTiles archive, far too large to ship in a container, so it is downloaded once into the data directory and served from there.

    Checking.

    The planet archive is around 128 GB. It resumes if interrupted, and Irfaran is usable while it runs. Progress and a re-download button live under Settings, Basemap.
